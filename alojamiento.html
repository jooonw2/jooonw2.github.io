PUBLICACIÓN WEB

Alojamiento web

Este portfolio está hecho con archivos estáticos. Está preparado para publicarse con GitHub Pages, el servicio de GitHub que sirve páginas web directamente desde un repositorio.

01

¿Qué tecnología usa?

HTML · CSS · JavaScript

El navegador carga los archivos de la web y la imagen. No necesita un servidor propio ni una base de datos.

02

¿Qué es GitHub Pages?

Alojamiento de sitios estáticos

GitHub publica los archivos seleccionados del repositorio y los sirve como una web accesible desde Internet.

03

¿Es gratis?

Sí, con GitHub Free

Para usar Pages con el plan gratuito, el repositorio debe ser público. El sitio publicado también es público.

04

¿Cómo se actualiza?

Al publicar cambios

Cuando se suben cambios al repositorio y se publica la rama o carpeta configurada, GitHub Pages vuelve a desplegar el sitio.

05

¿Tiene límites?

Pensado para sitios estáticos

GitHub indica un máximo de 1 GB para el sitio publicado y un límite orientativo de 100 GB de transferencia al mes.

EN ESTE PROYECTO

01

La portada y las subpáginas están guardadas como archivos HTML.

02

El aspecto visual compartido se define en style.css; la imagen está en la carpeta assets.

03

La dirección prevista para este sitio es jooonw2.github.io, el formato habitual de sitio personal de GitHub Pages.

La publicación efectiva depende de que GitHub Pages esté activado en la configuración del repositorio.

Consulta la documentación oficial: Introducción a GitHub Pages y límites del servicio.
