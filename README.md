# Jon Andrés — Portfolio

Portfolio personal de ciberseguridad para GitHub Pages.

## Estructura

- `index.html` — página principal.
- `sobre.html` — subpágina "Sobre esta página".
- `style.css` — estilos completos y responsive.
- `script.js` — animaciones ligeras.
- `assets/cybersecurity-background.png` — nueva imagen de fondo sin texto.

## Personalizar LinkedIn

En `index.html`, sustituye:

`https://www.linkedin.com/`

por tu URL real de LinkedIn.

## GitHub

El botón de GitHub apunta únicamente al perfil:

`https://github.com/jooonw2`

No se muestran ni sincronizan automáticamente repositorios.

## Subpágina

`sobre.html` incluye la información del proceso de creación y especifica:

- ChatGPT
- GPT-5.6 Luna
- ChatGPT Go
- HTML
- CSS
- JavaScript
- GitHub Pages

La página también deja claro que la IA se ha utilizado como herramienta de apoyo y que la personalización final pertenece a Jon Andrés.
